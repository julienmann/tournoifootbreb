Fonctionnement

1

Phase de groupes

2 groupes de 4 équipes. Chaque équipe joue 3 matchs contre les autres équipes de son groupe.

Victoire 3 pts · Nul 1 pt · Défaite 0 pt

2

Demi-finales

Les 2 meilleures équipes de chaque groupe se qualifient pour les demi-finales.

3

Finale

Les gagnants des demi-finales s'affrontent en finale pour déterminer le champion du tournoi.

Calendrier

Classements

MJ : matchs joués · V : victoires · N : nuls · D : défaites · BP : buts pour · BC : buts contre · DB : différence de buts · PTS : points (victoire 3, nul 1). Classement par PTS, puis DB. Les 2 premières équipes de chaque groupe (au-dessus du pointillé) se qualifient pour les demi-finales.

Code vestimentaire

  • Crampons interdits (naturel et turf)
  • Souliers de course et chaussettes autorisés
  • Protège-tibias recommandés (non obligatoires)
  • Aucun bijou (montre, chaîne, bracelets, etc.)

Règles de jeu

  • Pas de hors-jeu
  • Touches : peuvent être effectuées avec les mains ou les pieds
  • 7 joueurs maximum sur le terrain par équipe (incluant le gardien)
  • Minimum 5 joueurs pour débuter un match
  • Remplacements illimités :
    • doivent être approuvés par l'arbitre de touche
    • se font uniquement lors d'un arrêt de jeu
    • le gardien peut être sorti
  • Remise en jeu :
    • coup franc : tous les coups francs peuvent être tirés
    • distance du mur 5 mètres
    • coup d'envoi au centre
  • Temps mort (timeout) :
    • 1 par équipe par partie
    • durée : 1 minute
